# Our Blooms
This is a responsive flower shop website built from a Figma design.
## Tech stack
- React
- TypeScript
- Vite
- Tailwind CSS
- React Router
## Run project
Install dependencies:
```bash
npm install
```
Run dev:
```bash
npm run dev
```
Build:
```bash
npm run build
```
Lint:
```bash
npm run lint
```
## Project structure
```text
src/
├── assets/
├── components/
├── pages/
│   ├── Home/
│   ├── Gallery/
│   └── About/
├── AppLayout.tsx
├── router.tsx
├── main.tsx
└── index.css
```
## Responsive
Mobile: under 800px
Tablet: 800px - 1279px
Desktop: 1280px and above
The project uses responsive images and reusable components based on the original Figma design.
